## FortiGuard: what the licenses actually buy

A FortiGate without FortiGuard is still a stateful firewall, router and VPN gateway. Everything that depends on threat intelligence (antivirus signatures, IPS signatures, application control signatures, web and DNS ratings, IP reputation, outbreak prevention) depends on a **FortiGuard subscription** and on the FortiGate being able to reach FortiGuard servers. Support is a separate entitlement: **FortiCare**.

| Entitlement | What it covers |
|---|---|
| **FortiCare** support (Essentials, Premium, Elite) | Firmware upgrades, technical support (TAC), hardware RMA. FortiCare Premium is also the gate for some 8.0 features such as FortiAI-Assist. |
| **FortiGuard security services** | Signature and rating services: IPS, antivirus/anti-malware, application control, web filtering, DNS filtering, video filtering, antispam, IoT detection, inline CASB, DLP, outbreak prevention, attack surface security rating and others. |
| **Bundles** | Fortinet sells the services in tiers. **ATP** (Advanced Threat Protection) is the base security bundle (IPS, anti-malware, application control). **UTP** (Unified Threat Protection) adds web, DNS and video filtering and antispam. **Enterprise Protection** adds the advanced services (for example inline CASB, DLP, IoT detection, security rating). Every bundle includes FortiCare Premium. |
| **A-la-carte** | Individual services, for example FortiGuard IPS alone or a FortiSandbox Cloud subscription. |
| **VM licenses** | A FortiGate-VM also needs a VM license (vCPU entitlement). It can be a perpetual/subscription license file, a **FortiFlex** point-based token, or a cloud marketplace PAYG image where the license is billed through the cloud provider. |

> **Watch out:** Bundle contents change between Fortinet price-list revisions. On the exam you are expected to know the *idea* (ATP < UTP < Enterprise, each a superset of the one below) and to read the license status on a FortiGate, not to recite SKU contents.

### Checking license status

The GUI shows entitlements on the **Licenses** dashboard widget and under **System > FortiGuard**, where each service shows *Licensed*, *Expired*, or *Not licensed* together with the database versions.

From the CLI, the command most administrators use is:

```text
FGT-HQ # diagnose autoupdate versions
...
Virus Definitions
---------
Version: 93.07890 signed
Contract Expiry Date: Sat Oct 30 2027
Last Updated using manual update on Mon Oct 26 08:11:20 2026
Last Update Attempt: Thu Oct 29 06:01:47 2026
Result: No Updates
...
```

and to force an update immediately:

```text
FGT-HQ # execute update-now
```

### How FortiGate talks to FortiGuard

* **Updates** (signatures, engines) are pulled from the FortiGuard Distribution Network over HTTPS.
* **Ratings** (web filter, DNS filter, antispam, IP reputation lookups) are real-time queries. By default FortiOS uses **anycast** FortiGuard servers over HTTPS (TCP 443) (`set fortiguard-anycast enable` under `config system fortiguard`). Older designs used UDP 53 or UDP 8888 to unicast rating servers; you can still switch to those if a proxy or ISP blocks the anycast path.
* The FortiGate needs working DNS and a route to the internet from the management VDOM.

> **Exam tip:** "Web filter shows *Rating error*" or "FortiGuard unreachable" with an otherwise valid license is almost always DNS, routing or a blocked port from the management VDOM, not the license itself. Check `diagnose debug rating` for the server list and its state.

### The FortiGate-VM evaluation license

The permanent trial that this course's labs use is a VM license tied to a FortiCloud account. It is limited to 1 vCPU / 2 GB RAM, three interfaces, three firewall policies and three routes, low-encryption only, and **no FortiGuard services**. That means you can practise policies, NAT, routing, HA concepts, DHCP and diagnostics, but anything that needs live signatures or ratings (web filter categories, application control updates, FortiAI-Assist) needs a full license.

### Automatic firmware patching

`config system fortiguard` also holds the automatic firmware upgrade settings (`set auto-firmware-upgrade`, plus the day, delay and start/end hour). When enabled, the FortiGate installs **patch** releases within its current major/minor train during the configured window; it does not jump to a new major release.

## FortiGate as a DHCP server

Most branch and small-office FortiGates also hand out addresses to the LAN. The DHCP server is configured per interface, and that interface must have a static IP in the same subnet as the scope.

```text
FGT-HQ # config system dhcp server
FGT-HQ (server) # edit 1
FGT-HQ (1) # set interface "port2"
FGT-HQ (1) # set default-gateway 10.0.1.1
FGT-HQ (1) # set netmask 255.255.255.0
FGT-HQ (1) # set dns-service default
FGT-HQ (1) # set lease-time 86400
FGT-HQ (1) # config ip-range
FGT-HQ (ip-range) # edit 1
FGT-HQ (1) # set start-ip 10.0.1.100
FGT-HQ (1) # set end-ip 10.0.1.199
FGT-HQ (1) # next
FGT-HQ (ip-range) # end
FGT-HQ (1) # config reserved-address
FGT-HQ (reserved-address) # edit 1
FGT-HQ (1) # set ip 10.0.1.20
FGT-HQ (1) # set mac 00:0c:29:4a:11:20
FGT-HQ (1) # next
FGT-HQ (reserved-address) # end
FGT-HQ (1) # next
FGT-HQ (server) # end
```

| Setting | Notes |
|---|---|
| `default-gateway` | Usually the FortiGate's own interface IP. |
| `dns-service` | `default` hands out the DNS servers the FortiGate itself uses (system DNS); `local` hands out the interface IP, so clients use the FortiGate as their DNS server (DNS database or DNS forwarding must be enabled on that interface); `specify` lets you list servers with `dns-server1`...`dns-server4`. |
| `lease-time` | Seconds. The default is 604800 (seven days). |
| `ip-range` | One or more ranges; the GUI prefills the range from the interface subnet. |
| `reserved-address` | MAC-to-IP reservations. The action can also be `block` to deny a MAC an address. |
| `options` | Custom options by code, for example option 66/150 for IP phones or option 42 for NTP. |

Viewing and clearing leases (output columns trimmed):

```text
FGT-HQ # execute dhcp lease-list port2
port2
  IP              MAC-Address        Hostname          VCI             Expiry
  10.0.1.100      00:0c:29:4a:11:aa  LAB-PC1           MSFT 5.0        Fri Oct 30 09:12:41 2026
  10.0.1.20       00:0c:29:4a:11:20  PRN-01                            Fri Oct 30 08:55:02 2026

FGT-HQ # execute dhcp lease-clear all
```

### DHCP relay instead of a local server

If the LAN uses a central Windows or Infoblox DHCP server, the FortiGate relays instead of serving:

```text
FGT-HQ # config system interface
FGT-HQ (interface) # edit port2
FGT-HQ (port2) # set dhcp-relay-service enable
FGT-HQ (port2) # set dhcp-relay-ip "10.10.10.5"
FGT-HQ (port2) # next
FGT-HQ (interface) # end
```

The DHCP server must have a scope for the relay interface's subnet and a route back to the relay interface IP, because the FortiGate inserts that IP as the relay agent (giaddr) address.

> **Watch out:** You cannot run a DHCP server and DHCP relay on the same interface at the same time, and a DHCP server on an interface in DHCP-client mode makes no sense; the FortiGate GUI hides the DHCP server section until the interface is in **Manual** addressing mode.

### Troubleshooting DHCP

* Client gets 169.254.x.x: check that the server is enabled on the right interface (`show system dhcp server`), that the range is not exhausted (`execute dhcp lease-list`), and that the client VLAN actually lands on that interface.
* Sniff it: `diagnose sniffer packet port2 'port 67 or port 68' 4` shows Discover/Offer/Request/Ack.
* Debug the daemon: `diagnose debug application dhcps -1` followed by `diagnose debug enable`.

## Lab it yourself

1. On the trial VM, put a Linux or Windows host on `port2` and configure `port2` as 10.0.1.1/24.
2. Create the DHCP server above, renew the client lease and run `execute dhcp lease-list`.
3. Add a reservation for the client's MAC, clear the lease and confirm the client gets the reserved IP.
4. Change `dns-service` between `default`, `local` and `specify` and compare what the client receives (`ipconfig /all` or `resolvectl status`).
5. Run `diagnose autoupdate versions` and note that the trial shows no valid FortiGuard contracts; this is expected and is why the web filter labs need a full license.

## Key takeaways

* FortiCare = support and firmware; FortiGuard = security services (signatures and ratings). They are separate entitlements.
* Bundles stack: ATP (IPS, AV, app control) < UTP (adds web/DNS/video filtering, antispam) < Enterprise Protection (adds advanced services); all include FortiCare Premium.
* `diagnose autoupdate versions` shows contract expiry and database versions; `execute update-now` forces an update.
* Ratings use anycast FortiGuard over HTTPS 443 by default; UDP 53/8888 are the legacy alternatives.
* The DHCP server is per interface, needs a manually addressed interface, and supports ranges, reservations and custom options. Default lease is seven days.
* `dns-service default | local | specify` controls which DNS servers clients receive.
* `execute dhcp lease-list` and `diagnose debug application dhcps -1` are the DHCP troubleshooting tools.
