## A method for any "construct code" item

Topic 3.9 gives you requirements and an API reference excerpt and asks for the missing piece of a script, or the script itself. Work through the same checklist every time:

1. **Base URL and path**: from the docs, with path parameters filled in.
2. **Authentication**: API key header, token from a login call, cookie, or Basic on every call.
3. **Method and parameters**: query parameters for filters and paging, JSON body for writes.
4. **Headers**: `Accept`, `Content-Type`, and the vendor's auth header with its exact spelling.
5. **Where the data sits in the reply**: `response`, `imdata`, `data`, `items`, or a bare list.
6. **Paging and limits**: `Link` header, `offset`/`limit`, `page`/`page-size`; handle `429`.

Every script below reads secrets from environment variables, sets a `timeout`, and fails loudly with `raise_for_status()`. Host names are placeholders; replace them with your sandbox's.

| Platform | Auth | Device list | Data key |
|---|---|---|---|
| Meraki | `Authorization: Bearer <key>` | `GET /api/v1/organizations/{orgId}/devices` | bare list |
| Catalyst Center | `POST /dna/system/api/v1/auth/token` (Basic) → `X-Auth-Token` | `GET /dna/intent/api/v1/network-device` | `response` |
| ACI | `POST /api/aaaLogin.json` → `APIC-cookie` | `GET /api/class/topSystem.json` | `imdata[*].topSystem.attributes` |
| Catalyst SD-WAN | `POST /j_security_check` → `JSESSIONID`; `GET /dataservice/client/token` → `X-XSRF-TOKEN` | `GET /dataservice/device` | `data` |
| NSO | Basic on each call | `GET /restconf/data/tailf-ncs:devices/device` | `tailf-ncs:device` |

## 3.9.a Obtain a list of network devices

### Meraki

```python
import os
import time
import requests

BASE = "https://api.meraki.com/api/v1"
session = requests.Session()
session.headers.update({
    "Authorization": f"Bearer {os.environ['MERAKI_DASHBOARD_API_KEY']}",
    "Accept": "application/json",
})


def get_all(url, params=None):
    """GET every page of a paginated Meraki list, following Link: rel=next."""
    items = []
    while url:
        resp = session.get(url, params=params, timeout=30)
        if resp.status_code == 429:
            time.sleep(int(resp.headers.get("Retry-After", "1")))
            continue
        resp.raise_for_status()
        items.extend(resp.json())
        url = resp.links.get("next", {}).get("url")
        params = None  # the next link already carries the query string
    return items


org_id = get_all(f"{BASE}/organizations")[0]["id"]
for dev in get_all(f"{BASE}/organizations/{org_id}/devices", {"perPage": 1000}):
    print(dev["serial"], dev["model"], dev.get("name", ""), dev["networkId"])
```

The same with the SDK, which pages and retries for you:

```python
import meraki

dashboard = meraki.DashboardAPI(suppress_logging=True)
org_id = dashboard.organizations.getOrganizations()[0]["id"]
for dev in dashboard.organizations.getOrganizationDevices(org_id, total_pages="all"):
    print(dev["serial"], dev["model"], dev.get("name", ""))
```

### Catalyst Center

```python
import os
import requests

BASE = "https://catalyst.example.com"
auth = requests.post(f"{BASE}/dna/system/api/v1/auth/token",
                     auth=(os.environ["CC_USER"], os.environ["CC_PASSWORD"]),
                     headers={"Content-Type": "application/json"}, timeout=30)
auth.raise_for_status()
token = auth.json()["Token"]

session = requests.Session()
session.headers.update({"X-Auth-Token": token, "Accept": "application/json"})

offset, limit = 1, 500                       # offset is 1-based; limit max 500
while True:
    resp = session.get(f"{BASE}/dna/intent/api/v1/network-device",
                       params={"offset": offset, "limit": limit}, timeout=30)
    resp.raise_for_status()
    page = resp.json()["response"]
    for dev in page:
        print(dev["hostname"], dev["managementIpAddress"], dev["platformId"],
              dev["reachabilityStatus"])
    if len(page) < limit:
        break
    offset += limit
```

### ACI (APIC)

```python
import os
import requests

APIC = "https://apic.example.com"
session = requests.Session()
login = {"aaaUser": {"attributes": {"name": os.environ["APIC_USER"],
                                    "pwd": os.environ["APIC_PASSWORD"]}}}
resp = session.post(f"{APIC}/api/aaaLogin.json", json=login, timeout=30)
resp.raise_for_status()
token = resp.json()["imdata"][0]["aaaLogin"]["attributes"]["token"]
session.cookies.set("APIC-cookie", token)    # the Set-Cookie already did this; explicit for clarity

resp = session.get(f"{APIC}/api/class/topSystem.json", timeout=30)
resp.raise_for_status()
for item in resp.json()["imdata"]:
    node = item["topSystem"]["attributes"]
    print(node["name"], node["role"], node["address"], node["serial"])
```

### Catalyst SD-WAN Manager

```python
import os
import requests

MANAGER = "https://sdwan.example.com"
session = requests.Session()
resp = session.post(f"{MANAGER}/j_security_check",
                    data={"j_username": os.environ["SDWAN_USER"],
                          "j_password": os.environ["SDWAN_PASSWORD"]},
                    timeout=30)
if resp.status_code != 200 or "<html" in resp.text.lower():
    raise SystemExit("SD-WAN Manager login failed")   # failure returns a login page

xsrf = session.get(f"{MANAGER}/dataservice/client/token", timeout=30)
xsrf.raise_for_status()
session.headers["X-XSRF-TOKEN"] = xsrf.text           # needed for POST/PUT/DELETE

try:
    resp = session.get(f"{MANAGER}/dataservice/device", timeout=30)
    resp.raise_for_status()
    for dev in resp.json()["data"]:
        print(dev["host-name"], dev["system-ip"], dev["device-type"],
              dev["reachability"])
finally:
    session.post(f"{MANAGER}/logout", timeout=30)
```

`data=` form-encodes the credentials, which is what `/j_security_check` expects. The `JSESSIONID` cookie is kept by the session automatically.

## 3.9.b Manage spaces, participants and messages in Webex

```python
import os
import requests

BASE = "https://webexapis.com/v1"
session = requests.Session()
session.headers.update({"Authorization": f"Bearer {os.environ['WEBEX_ACCESS_TOKEN']}"})


def call(method, path, **kwargs):
    resp = session.request(method, f"{BASE}{path}", timeout=30, **kwargs)
    resp.raise_for_status()
    return resp.json() if resp.content else None


# 1. Create a space (a "room" in the API); the reply carries its id.
room = call("POST", "/rooms", json={"title": "NOC change window"})
room_id = room["id"]

# 2. Add a participant (a membership).
call("POST", "/memberships", json={"roomId": room_id, "personEmail": "alice@example.com"})

# 3. Post a message.
call("POST", "/messages", json={"roomId": room_id,
                                "markdown": "**Change 42** starts at 22:00 UTC"})

# 4. Read back members and messages (roomId is required for /messages).
for m in call("GET", "/memberships", params={"roomId": room_id})["items"]:
    print("member:", m["personEmail"])
for msg in call("GET", "/messages", params={"roomId": room_id, "max": 50})["items"]:
    print("message:", msg.get("text"))

# 5. Clean up: delete the space (204 No Content, so no JSON body).
call("DELETE", f"/rooms/{room_id}")
```

Details the documentation fixes:

- Creates (`POST /rooms`, `/memberships`, `/messages`) return **`200 OK`** with the new object; deletes return **`204 No Content`**.
- `POST /rooms` requires `title`. `POST /memberships` requires `roomId` and takes `personEmail` or `personId` (and `isModerator`). `POST /messages` needs a destination (`roomId`, `toPersonEmail` or `toPersonId`) and content (`text`, `markdown`, `files` or a card in `attachments`).
- Lists come back as `{"items": [...]}` and page with `max` plus a `Link: <...>; rel="next"` header.
- To remove one participant: find the membership `id` with `GET /memberships?roomId=...`, then `DELETE /memberships/{membershipId}`.

The SDK version of the same flow is in lesson 3.1 (`api.rooms.create`, `api.memberships.create`, `api.messages.create`).

## 3.9.c Obtain a list of clients or hosts

### Meraki: clients seen on a network

```python
import os
import requests

BASE = "https://api.meraki.com/api/v1"
NETWORK_ID = "N_1001"                       # from GET /organizations/{orgId}/networks
session = requests.Session()
session.headers["Authorization"] = f"Bearer {os.environ['MERAKI_DASHBOARD_API_KEY']}"

url = f"{BASE}/networks/{NETWORK_ID}/clients"
params = {"timespan": 86400, "perPage": 1000}   # last 24 h; default perPage is only 10
while url:
    resp = session.get(url, params=params, timeout=30)
    resp.raise_for_status()
    for client in resp.json():
        print(client["mac"], client.get("ip"), client.get("description"),
              client.get("vlan"), client.get("status"))
    url = resp.links.get("next", {}).get("url")
    params = None
```

### Catalyst Center: clients

```python
import os
import time
import requests

BASE = "https://catalyst.example.com"
token = requests.post(f"{BASE}/dna/system/api/v1/auth/token",
                      auth=(os.environ["CC_USER"], os.environ["CC_PASSWORD"]),
                      timeout=30).json()["Token"]
headers = {"X-Auth-Token": token, "Accept": "application/json"}

now_ms = int(time.time() * 1000)            # times are epoch milliseconds
params = {"startTime": now_ms - 3600 * 1000, "endTime": now_ms,
          "limit": 100, "offset": 1}
resp = requests.get(f"{BASE}/dna/data/api/v1/clients", headers=headers,
                    params=params, timeout=30)
resp.raise_for_status()
body = resp.json()
for client in body["response"]:
    print(client["macAddress"], client.get("ipv4Address"), client["type"],
          client.get("siteHierarchy"))
print("page:", body["page"])
```

For a single host by MAC address, `GET /dna/intent/api/v1/client-detail?macAddress=00:11:22:33:44:55` returns its `detail` (host name, IP, wired or wireless, connection status).

## Lab it yourself

1. Create an empty folder, a virtual environment in it (`python -m venv .venv`, then activate it with `.venv\Scripts\activate` on Windows or `source .venv/bin/activate` on macOS and Linux), and `pip install requests meraki` (the current `meraki` package needs Python 3.11 or later).
2. Reserve the Meraki sandbox and run the Meraki device and client scripts; change `perPage` to 3 and print `resp.headers["Link"]` to watch the paging.
3. Reserve the Catalyst Center sandbox and run both Catalyst Center scripts; compare `limit=2&offset=1` with `offset=3`.
4. Run the Webex script with your own personal access token; then check the Webex app to see the space appear and disappear.
5. If ACI, SD-WAN or NSO sandboxes are available in the catalog, reserve one at a time (one active reservation is allowed) and run the matching script.

## Key takeaways

- Read the docs for six things: URL, auth, method and parameters, headers, the reply's data key, and paging.
- Meraki: Bearer key, bare-list replies, `Link` paging via `resp.links`, back off on `429`; the SDK does this with `total_pages="all"`.
- Catalyst Center: token from `/dna/system/api/v1/auth/token` → `X-Auth-Token`; data under `response`; `offset` 1-based, `limit` up to 500; clients at `/dna/data/api/v1/clients` with epoch-millisecond times.
- ACI: `aaaLogin` → `APIC-cookie` (a `requests.Session` keeps it), class query, loop over `imdata`.
- SD-WAN Manager: form login to `/j_security_check`, XSRF token from `/dataservice/client/token`, devices under `data`, log out.
- NSO: Basic auth, `/restconf/data/tailf-ncs:devices/device`, `Accept: application/yang-data+json`, key `tailf-ncs:device`.
- Webex: `POST /rooms` (title), `POST /memberships` (roomId + personEmail), `POST /messages` (roomId + text/markdown), `GET /messages?roomId=`, `DELETE /rooms/{id}`; lists in `items`.
