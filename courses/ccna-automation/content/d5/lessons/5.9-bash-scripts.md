## From commands to scripts

Lesson 4.11 covered the individual commands: `cd`, `ls`, `cp`, `mv`, `rm`, `mkdir`, `chmod`, `grep`, `find` and environment variables. Topic 5.9 puts them in a script and asks what the script does. Cisco's examples are **file management**, **app install**, **user management** and **directory navigation**. Read the script **top to bottom**, the way Bash runs it, keeping track of three things: the **current directory**, the **variables**, and the **exit status** of the last command.

All output in this lesson comes from running the scripts with Bash 5.3 and GNU coreutils in a throwaway directory; the home directory is shown as `/home/alice`. The install-and-user script was only syntax-checked (`bash -n`) and run as an ordinary user, because it needs root.

## The parts of a script

| Part | Example | Meaning |
|---|---|---|
| **Shebang** | `#!/usr/bin/env bash` or `#!/bin/bash` | The first line names the interpreter when the file is executed as `./script.sh` (after `chmod +x`). `env` finds `bash` on the `PATH`. `bash script.sh` ignores the shebang |
| **Strict mode** | `set -euo pipefail` | `-e`: exit when a command fails (not inside an `if` test, `while`/`until` condition, or any but the last command of an `&&`/`\|\|` list); `-u`: treat an unset variable as an error; `-o pipefail`: a pipeline fails if any command in it fails, not just the last |
| **Variables** | `DEST="$HOME/archive"` | No spaces around `=`. Read with `"$DEST"` or `"${DEST}"`. `${1:-default}` is argument 1, or `default` if it is missing or empty |
| **Command substitution** | `stamp=$(date +%F)` | Runs the command and inserts its output (`2026-11-22`) |
| **Arrays** | `PACKAGES=(git rsync)`, `"${PACKAGES[@]}"` | Each element expands as one word |
| **Tests** | `[[ -d "$SRC" ]]`, `[[ $EUID -ne 0 ]]`, `[[ -z "$x" ]]` | `-d` directory exists, `-f` regular file, `-e` exists, `-z` empty string, `-n` non-empty, `-eq -ne -lt -gt` numbers, `==` `!=` strings |
| **Conditionals** | `if cmd; then ...; elif ...; else ...; fi` | `if` tests the **exit status** of any command, not just `[[ ]]`: `if id -u bob >/dev/null 2>&1; then` |
| **Loops** | `for f in *.cfg; do ...; done`, `while read -r line; do ...; done < file` | `for` iterates over words or glob matches |
| **Exit status** | `$?`, `exit 2` | `0` is success, anything else is failure. A script's status is that of its `exit`, or of its last command |
| **Redirection** | `> file`, `>> file`, `2>&1`, `>&2`, `>/dev/null`, `< file` | Overwrite, append, send stderr where stdout goes, write to stderr, discard, read from a file |
| **Operators** | `cmd1 && cmd2`, `cmd1 \|\| cmd2`, `cmd1 \| cmd2` | Run `cmd2` only if `cmd1` succeeded, only if it failed, or feed `cmd1`'s output to `cmd2` |

## Quoting matters

```bash
#!/usr/bin/env bash
f="core sw01.cfg"
touch "$f"
ls $f
ls "$f"
```

```text
ls: cannot access 'core': No such file or directory
ls: cannot access 'sw01.cfg': No such file or directory
core sw01.cfg
```

Unquoted, `$f` splits into two words. Always quote variable expansions: `"$f"`, `"$DEST/"`, `"${PACKAGES[@]}"`.

## File management and directory navigation

```bash
#!/usr/bin/env bash
# archive-configs.sh - copy today's device configs into a dated archive folder
set -euo pipefail

SRC="${1:-$HOME/configs}"
DEST="$HOME/archive/$(date +%F)"

if [[ ! -d "$SRC" ]]; then
    echo "error: $SRC is not a directory" >&2
    exit 2
fi

mkdir -p "$DEST"
cd "$SRC"
count=0
for f in *.cfg; do
    [[ -e "$f" ]] || continue          # no match: the glob stays literal
    cp -- "$f" "$DEST/"
    count=$((count + 1))
done

cd "$DEST"
echo "archived $count files to $(pwd)"
find "$HOME/archive" -mindepth 1 -maxdepth 1 -type d -mtime +30 -exec rm -rf -- {} +
```

Read it top to bottom:

1. Strict mode on.
2. `SRC` is the first argument, or `~/configs` if none was given. `DEST` is a folder named for today's date under `~/archive`.
3. If `SRC` is not a directory, print an error **to stderr** and exit with status **2**.
4. Create `DEST` and any missing parents (`-p`: no error if it exists).
5. **Navigate** into `SRC`, so the glob `*.cfg` matches files there.
6. Copy every `.cfg` file into `DEST`, counting them. `--` ends options, so a file named `-x.cfg` is not read as a flag. The `[[ -e ]] || continue` line handles a folder with no `.cfg` files: without it the loop would run once with the literal string `*.cfg`.
7. Navigate into `DEST` and report.
8. Delete archive folders last modified more than 30 days ago.

With three `.cfg` files and a `README.txt` in `~/configs`:

```text
alice@devbox:~$ ./archive-configs.sh
archived 3 files to /home/alice/archive/2026-11-22
alice@devbox:~$ echo $?
0
alice@devbox:~$ ./archive-configs.sh /home/alice/nope
error: /home/alice/nope is not a directory
alice@devbox:~$ echo $?
2
```

`README.txt` is not copied: it does not match `*.cfg`.

> **Watch out:** `((count++))` looks equivalent to `count=$((count + 1))`, but under `set -e` it ends the script when `count` is 0: the expression's value is the old value, 0, and an arithmetic command whose value is 0 returns status 1. Running `set -e; count=0; ((count++)); echo "count is $count"` prints nothing and exits with status 1.

Navigation helpers you will see: `cd -` returns to the previous directory, `pushd dir` changes directory and remembers where you were, `popd` goes back. `cd` inside a script changes only the script's own process; the caller's shell stays where it was.

## App install and user management

```bash
#!/usr/bin/env bash
# setup-netbackup.sh - prepare a Debian or Ubuntu host to run nightly config backups
set -euo pipefail

SVC_USER="netbackup"
APP_DIR="/opt/netbackup"
BACKUP_DIR="/var/backups/network"
PACKAGES=(git python3-venv rsync)

if [[ $EUID -ne 0 ]]; then
    echo "run as root: sudo $0" >&2
    exit 1
fi

# App install: install only what is missing
apt-get update -qq
for pkg in "${PACKAGES[@]}"; do
    if dpkg -s "$pkg" >/dev/null 2>&1; then
        echo "already installed: $pkg"
    else
        apt-get install -y -qq "$pkg"
    fi
done

# User management: a system account with no interactive shell
if ! id -u "$SVC_USER" >/dev/null 2>&1; then
    useradd --system --home-dir "$APP_DIR" --shell /usr/sbin/nologin "$SVC_USER"
fi
usermod -aG "$SVC_USER" alice

# File management
mkdir -p "$APP_DIR" "$BACKUP_DIR"
chown "$SVC_USER:$SVC_USER" "$BACKUP_DIR"
chmod 750 "$BACKUP_DIR"

# Directory navigation: build the virtual environment inside the app directory
cd "$APP_DIR"
python3 -m venv venv
./venv/bin/pip install --quiet netmiko
chown -R "$SVC_USER:$SVC_USER" "$APP_DIR"

echo "setup complete in $(pwd)"
```

| Block | Commands | What happens |
|---|---|---|
| Guard | `[[ $EUID -ne 0 ]]` | Not root: message on stderr, exit 1, nothing changed. Run as `alice`, it prints `run as root: sudo ./setup-netbackup.sh` |
| App install | `apt-get update`, `dpkg -s`, `apt-get install -y` | Refresh the package index, then install each package only if `dpkg -s` says it is missing; `-y` answers yes. On RHEL the equivalents are `dnf install -y` and `rpm -q` |
| User management | `id -u`, `useradd --system`, `usermod -aG` | Create the `netbackup` system account (home `/opt/netbackup`, no login shell) only if it does not exist; add `alice` to the `netbackup` group. **`-aG` appends**; `-G` without `-a` would replace alice's supplementary groups. Other commands: `userdel`, `groupadd`, `passwd`, `chage` |
| File management | `mkdir -p`, `chown`, `chmod 750` | Create both directories; the backup folder belongs to `netbackup`, readable by its group, closed to others |
| Navigation and app setup | `cd`, `python3 -m venv`, `./venv/bin/pip` | Create a virtual environment in `/opt/netbackup/venv` and install Netmiko into it; `./venv/...` works because of the `cd` |

**Workflow in one sentence:** on a Debian or Ubuntu host, as root, install git, python3-venv and rsync if missing, create a no-login `netbackup` service account and add alice to its group, create its application and backup directories with restricted permissions, and install Netmiko into a virtual environment for it.

The structure "check, then act" (`dpkg -s` before install, `id -u` before `useradd`) makes the script safe to run twice, the hand-written version of Ansible's idempotency (lesson 5.8). Bash has no handlers and no `changed` report; the script has to do that bookkeeping itself.

## Other things to recognise

- `while IFS= read -r host; do ...; done < hosts.txt` reads a file line by line.
- `case "$1" in start) ...;; stop) ...;; *) echo "usage"; exit 64;; esac` dispatches on an argument.
- `trap 'rm -f "$tmp"' EXIT` runs clean-up however the script ends.
- `systemctl enable --now rsyslog` and `systemctl stop cups` start and stop services; `sudo` runs one command as root.
- `curl -fsSL https://... -o file` downloads a file and fails on HTTP errors (`-f`).

## Lab it yourself

1. Use Bash on Linux, the Terminal on macOS (it ships Bash 3.2 at `/bin/bash`; these scripts work with it, or install a newer Bash with Homebrew), or WSL 2 or Git Bash on Windows.
2. Create `~/configs` with a few `.cfg` files and one `.txt`, save `archive-configs.sh`, `chmod +x` it, and run it with no argument, with a missing directory, and with an empty directory. Check `echo $?` each time.
3. Remove the `[[ -e "$f" ]] || continue` line and run it on the empty directory; read the error.
4. Run `bash -n setup-netbackup.sh` to check its syntax without running it, and `bash -x archive-configs.sh` to trace every command as it runs.

## Key takeaways

- Read a script top to bottom, tracking the current directory, the variables and the last exit status.
- `#!/usr/bin/env bash` picks the interpreter; `set -euo pipefail` stops on errors, unset variables and failed pipelines.
- Quote every expansion; `${1:-default}` supplies a default argument.
- `if` tests a command's exit status; `[[ -d ]]`, `-f`, `-e`, `-z` and numeric `-eq`/`-ne` are the common tests.
- `exit N` sets the script's status; `0` is success; errors go to stderr with `>&2`.
- App install: `apt-get`/`dnf` with a `dpkg -s`/`rpm -q` check. Users: `id`, `useradd --system`, `usermod -aG` (append).
- `cd` and `pushd`/`popd` change where relative paths and globs resolve; the caller's directory is unchanged.
