## Where you run queries

**Kusto Query Language (KQL)** is the read-only language for Azure Monitor Logs. You run it in:

- **Monitor** > **Logs**, or **Logs** on a Log Analytics workspace (workspace context, all tables you can read).
- **Logs** on a VM, resource group or other resource (resource context: only that resource's records).
- Log search alert rules, workbooks, dashboards, Azure CLI and PowerShell.

```bash
az monitor log-analytics query --workspace <workspace-id> \
  --analytics-query "Heartbeat | summarize LastSeen = max(TimeGenerated) by Computer" -o table
```

```powershell
$r = Invoke-AzOperationalInsightsQuery -WorkspaceId '<workspace-id>' -Query 'Heartbeat | summarize LastSeen = max(TimeGenerated) by Computer'
$r.Results | Format-Table
```

`<workspace-id>` here is the workspace **customer ID** (a GUID on the workspace Overview page), not its resource ID. In the portal the time picker adds a time filter unless the query has its own on `TimeGenerated`.

## Tables you'll meet on the exam

| Table | Filled by | Useful columns |
|---|---|---|
| **AzureActivity** | Activity log diagnostic setting | `OperationNameValue`, `ActivityStatusValue`, `Caller`, `CategoryValue`, `ResourceGroup`, `Level` |
| **Heartbeat** | Azure Monitor Agent, once a minute | `Computer`, `OSType`, `Category`, `ComputerIP`, `ResourceGroup` |
| **Perf** | AMA performance counters (DCR) | `Computer`, `ObjectName`, `CounterName`, `InstanceName`, `CounterValue` |
| **Event** | AMA Windows event logs (DCR) | `Computer`, `EventLog`, `EventLevelName`, `EventID`, `Source`, `RenderedDescription` |
| **Syslog** | AMA Linux Syslog (DCR) | `Computer`, `Facility`, `SeverityLevel`, `ProcessName`, `SyslogMessage` |
| **InsightsMetrics** | VM insights (logs-based) and other solutions | `Computer`, `Namespace`, `Name`, `Val`, `Tags` |
| **AzureMetrics** | Diagnostic setting with `AllMetrics` | `Resource`, `MetricName`, `Average`, `Maximum`, `Minimum`, `Total`, `Count`, `TimeGrain` |
| **AzureDiagnostics** | Diagnostic settings in Azure diagnostics mode | `ResourceProvider`, `Category`, `OperationName`, plus many service columns |
| Resource-specific tables | Diagnostic settings in resource-specific mode | e.g. `StorageBlobLogs`, `AddonAzureBackupJobs`, `NTANetAnalytics` |

Every table has `TimeGenerated` (when the record was created) and `Type` (the table name).

## The operators that matter

A query starts with a table and pipes rows through operators with `|`. Each operator returns a new table.

| Operator | Does | Example |
|---|---|---|
| `where` | Keeps rows where the predicate is true | `where TimeGenerated > ago(1h) and Computer startswith "vm-web"` |
| `project` | Chooses, renames or computes columns (drops the rest) | `project TimeGenerated, Computer, CPU = CounterValue` |
| `project-away` | Drops named columns | `project-away TenantId` |
| `extend` | Adds a computed column, keeps the rest | `extend GB = Bytes / 1024 / 1024 / 1024` |
| `summarize` | Aggregates rows into groups | `summarize count(), avg(CounterValue) by Computer` |
| `bin()` | Rounds values down into buckets, usually time | `summarize avg(CounterValue) by bin(TimeGenerated, 5m)` |
| `sort by` / `order by` | Sorts; **default is descending** | `sort by AvgCPU asc` |
| `top N by` | Sorts and keeps N rows (default descending) | `top 3 by CounterValue` |
| `take` / `limit` | Returns N rows, **no order guaranteed** | `take 10` |
| `count` | Returns one row with the number of rows | `Heartbeat | count` |
| `distinct` | Unique combinations | `distinct Computer` |
| `join` | Combines two tables on a key | `join kind=leftouter (T2) on Computer` |
| `union` | Appends tables | `union Event, Syslog` |
| `render` | Draws a chart | `render timechart` |
| `search` | Full-text search across columns and tables | `search "timeout"` |

Common aggregation functions inside `summarize`: `count()`, `countif()`, `dcount()` (distinct count), `sum()`, `avg()`, `min()`, `max()`, `percentile(x, 95)`, `arg_max(TimeGenerated, *)` (the latest row per group), `make_set()`.

String comparisons: `==` is case-sensitive, `=~` case-insensitive, `has` matches whole terms (fast), `contains` matches substrings (slower), `startswith`, `in ("a","b")`.

Time: `ago(1h)`, `ago(7d)`, `now()`, `between (datetime(2026-11-20) .. datetime(2026-11-21))`, `startofday(now())`.

> **Exam tip:** `take` gives "some rows", not the top rows. If a question asks for the highest values, the answer uses `top N by` or `sort by` then `take`.

## Read a query against a sample

Sample `Perf` rows (all ObjectName `Processor`, CounterName `% Processor Time`, InstanceName `_Total`, within the last hour):

| TimeGenerated | Computer | CounterValue |
|---|---|---|
| 10:01 | vm-web-01 | 35 |
| 10:03 | vm-web-02 | 80 |
| 10:06 | vm-web-01 | 45 |
| 10:08 | vm-sql-01 | 90 |
| 10:11 | vm-web-02 | 70 |
| 10:12 | vm-sql-01 | 60 |

```kusto
Perf
| where TimeGenerated > ago(1h)
| where ObjectName == "Processor" and CounterName == "% Processor Time"
| summarize AvgCPU = avg(CounterValue), Samples = count() by Computer
| where AvgCPU > 50
| sort by AvgCPU desc
```

Work it: vm-web-01 averages (35 + 45) / 2 = 40; vm-web-02 (80 + 70) / 2 = 75; vm-sql-01 (90 + 60) / 2 = 75. The second `where` drops vm-web-01. Two rows remain, each with Samples 2 and AvgCPU 75; their order is a tie.

Now bucket by time:

```kusto
Perf
| where CounterName == "% Processor Time"
| summarize MaxCPU = max(CounterValue) by bin(TimeGenerated, 5m)
```

`bin(TimeGenerated, 5m)` rounds down: 10:01 and 10:03 go to the 10:00 bucket (max 80), 10:06 and 10:08 to 10:05 (max 90), 10:11 and 10:12 to 10:10 (max 70). Three rows.

### Find machines that stopped sending heartbeats

```kusto
Heartbeat
| summarize LastHeartbeat = max(TimeGenerated) by Computer
| where LastHeartbeat < ago(15m)
```

### Who deleted resources this week

```kusto
AzureActivity
| where TimeGenerated > ago(7d)
| where OperationNameValue endswith "/DELETE" and ActivityStatusValue == "Success"
| project TimeGenerated, Caller, ResourceGroup, OperationNameValue
| sort by TimeGenerated desc
```

### Windows errors per computer, charted

```kusto
Event
| where EventLevelName == "Error" and TimeGenerated > ago(1d)
| summarize Errors = count() by Computer, bin(TimeGenerated, 1h)
| render timechart
```

### join

`join` matches rows from the left and right tables on a key. The default flavor is **innerunique**: it removes duplicate keys from the **left** side first, then keeps only matching rows. Name the flavor explicitly when it matters:

| kind | Returns |
|---|---|
| `innerunique` (default) | Matches, left side deduplicated by key |
| `inner` | Every matching combination |
| `leftouter` | All left rows, with right columns empty when there's no match |
| `leftanti` | Left rows with **no** match (great for "which VMs have no heartbeat") |
| `leftsemi` | Left rows that have a match, left columns only |

```kusto
let vms = datatable(Computer:string, Owner:string) ["vm-web-01","Ana", "vm-web-02","Raj", "vm-app-01","Lee"];
vms
| join kind=leftanti (Heartbeat | where TimeGenerated > ago(1h) | distinct Computer) on Computer
```

If only vm-web-01 and vm-web-02 sent heartbeats in the last hour, the result is the vm-app-01 row.

### search

`search "disk full"` looks in every column of every table in scope; `search in (Event, Syslog) "disk"` narrows it. Handy for exploration, slow and costly for alerts.

## Writing queries well

- Filter on time first, then on other columns, then aggregate.
- Use `project` to cut columns before `join`.
- Use `has` over `contains` when matching whole words.
- Save useful queries as **query packs** or functions, and pin results to a dashboard or workbook.

## Key takeaways

- Know the tables: AzureActivity, Heartbeat, Perf, Event, Syslog, InsightsMetrics, AzureMetrics, AzureDiagnostics, and resource-specific tables.
- `where` filters rows, `project` picks columns, `extend` adds columns, `summarize ... by` aggregates, `bin()` buckets time.
- `sort by` and `top` default to **descending**; `take` returns arbitrary rows.
- `join` defaults to `innerunique`; `leftanti` finds missing matches.
- Filter on `TimeGenerated` with `ago()` first; use `has`, `==` and `=~` deliberately.
