## Why Python, and which Python

Shell scripts (lesson 4.2) are ideal for gluing commands together. When a task needs real data structures, JSON or API calls, error handling or more than a page of logic, administrators switch to **Python**: it is installed on nearly every Linux system, Ansible's modules are written in it, and tools such as `dnf`, `firewalld` and `cloud-init` are Python programs.

**Use Python 3 only.** Python 2 reached end of life on 1 January 2020 (2.7 was the last release); code with `print "hello"` is Python 2 and fails under Python 3:

```text
alice@srv01:~$ python3 p2.py
  File "/home/alice/p2.py", line 1
    print "hello"
    ^^^^^^^^^^^^^
SyntaxError: Missing parentheses in call to 'print'. Did you mean print(...)?
```

Python 3 has a new feature release every October with five years of support. As of late 2026, **3.15** (October 2026) and **3.14** receive bug fixes, 3.11 to 3.13 receive security fixes only, and 3.10 reached end of life in October 2026. Distributions ship their own version and support it for the distribution's lifetime: RHEL 9 uses 3.9 as the system Python (newer versions available as `python3.11`, `python3.12`), RHEL 10 and Ubuntu 24.04 use 3.12, Debian 12 uses 3.11 and Debian 13 uses 3.13. Check with `python3 --version`.

Call the interpreter **`python3`**. A bare `python` command may not exist (on RHEL 9 it comes from the `python-unversioned-command` package, which is not installed on every system, and Red Hat recommends it only for interactive use; Debian and Ubuntu need the `python-is-python3` package), and on very old systems it meant Python 2. Scripts start with `#!/usr/bin/env python3` or `#!/usr/bin/python3`.

## Fundamentals: indentation

Python marks blocks by **indentation**, not braces or `fi`/`done`. Every line in a block must be indented by the same amount, and PEP 8 says **4 spaces** (no tabs). A colon ends the line that opens a block (`if`, `for`, `while`, `def`, `class`, `with`, `try`).

```python
def check(port):
    if port < 1024:
        print("privileged port")
    return port
```

Mixing levels is a hard error, not a style issue:

```text
alice@srv01:~$ python3 bad.py
  File "/home/alice/bad.py", line 4
    print("done")
                 ^
IndentationError: unindent does not match any outer indentation level
```

## Data types

| Type | Example | Notes |
|---|---|---|
| **Boolean** (`bool`) | `True`, `False` | Capitalised. Empty strings, empty lists, `0` and `None` count as false in an `if` |
| **Integer** (`int`) | `22`, `-1`, `1_000_000` | Unlimited size |
| **Floating point** (`float`) | `0.75`, `1e-3` | Binary floating point: `0.1 + 0.2` is `0.30000000000000004`. `7 / 2` is `3.5`; `7 // 2` is integer division, `3` |
| **String** (`str`) | `"srv01"`, `'web'`, `f"{name}:{port}"` | Immutable text. f-strings insert values. Methods: `.split()`, `.strip()`, `.upper()`, `.startswith()` |
| **List** (`list`) | `["web01", "web02"]` | Ordered and changeable; index from 0, `[-1]` is the last item; `.append()`, `len()` |
| **Dictionary** (`dict`) | `{"name": "sshd", "port": 22}` | Key-value pairs; `d["port"]`, `d.get("user", "root")` returns a default instead of raising `KeyError` |

Others you will meet: `tuple` (`(1, 2)`, an unchangeable list), `set` (unique items) and `None` (no value). Python is dynamically but **strongly** typed: `"5" + 5` raises `TypeError: can only concatenate str (not "int") to str`, so convert explicitly with `int()`, `float()` and `str()`.

```text
alice@srv01:~$ cat types_demo.py
enabled = True                       # bool
port = 22                            # int
load = 0.75                          # float
name = "srv01"                       # str
hosts = ["web01", "web02"]           # list (ordered, changeable)
svc = {"name": "sshd", "port": 22}   # dict (key -> value)

for value in (enabled, port, load, name, hosts, svc):
    print(type(value).__name__, value)

hosts.append("db01")
print(len(hosts), hosts[0], hosts[-1])
print(svc["port"], svc.get("user", "root"))
print(7 / 2, 7 // 2, 0.1 + 0.2)
print(int("10") + 5, "10" + "5", f"{name}:{port}")
print(bool(""), bool("0"), bool([]), bool(0))
alice@srv01:~$ python3 types_demo.py
bool True
int 22
float 0.75
str srv01
list ['web01', 'web02']
dict {'name': 'sshd', 'port': 22}
3 web01 db01
22 root
3.5 3 0.30000000000000004
15 105 srv01:22
False True False False
```

Note `bool("0")` is `True`: it is a non-empty string.

## Modules and packages

Python is extended with **modules** (one `.py` file) and **packages** (a directory of modules). You load them with `import`:

```python
import json                      # whole module, used as json.dumps()
from pathlib import Path         # one name from a module
import subprocess as sp          # alias
```

The **standard library** ships with Python, so these **built-in modules** need no installation:

| Module | Use |
|---|---|
| `os`, `sys` | Environment (`os.environ`), process info, arguments (`sys.argv`), exit codes (`sys.exit(1)`) |
| `subprocess` | Run commands: `subprocess.run(["systemctl", "is-active", "nginx"], capture_output=True, text=True)`; pass a **list**, avoid `shell=True` with untrusted input |
| `pathlib`, `shutil` | Paths and files; `shutil.copy()`, `shutil.disk_usage()` |
| `json`, `csv` | Parse and write data files and API responses |
| `re` | Regular expressions |
| `argparse` | Command-line options and `--help` |
| `logging` | Log levels and handlers instead of `print` |
| `socket`, `datetime`, `platform`, `hashlib` | Networking, time, system information, checksums |

Third-party packages (requests, PyYAML, paramiko, Jinja2) come from **PyPI**, the Python Package Index, installed with **pip**, or from distribution packages named `python3-<name>` (`dnf install python3-requests`, `apt install python3-requests`).

A small real tool that uses only the standard library:

```text
alice@srv01:~$ cat disk_report.py
#!/usr/bin/env python3
"""Report filesystems above a usage threshold."""
import json
import shutil
import sys

THRESHOLD_PERCENT = 80.0


def usage_percent(path: str) -> float:
    total, used, _free = shutil.disk_usage(path)
    return round(used / total * 100, 1)


def main() -> int:
    paths = sys.argv[1:] or ["/"]
    report = {}
    for path in paths:
        report[path] = usage_percent(path)
    over = [p for p, pct in report.items() if pct >= THRESHOLD_PERCENT]
    print(json.dumps({"usage": report, "over_threshold": over}))
    return 1 if over else 0


if __name__ == "__main__":
    sys.exit(main())
alice@srv01:~$ python3 disk_report.py / /tmp; echo "exit=$?"
{"usage": {"/": 53.9, "/tmp": 34.9}, "over_threshold": []}
exit=0
```

`if __name__ == "__main__":` runs `main()` only when the file is executed, not when another script imports it, and `sys.exit()` hands a shell-style exit status back to cron, systemd or a CI job.

## Virtual environments and installing dependencies

Installing PyPI packages into the system Python with `sudo pip install` can overwrite files that the package manager owns and break tools like `dnf`. Current Debian (12 and later) and Ubuntu (23.04 and later) therefore mark their system Python as **externally managed** (**PEP 668**), and pip refuses to install into it outside a virtual environment, both system-wide (`sudo pip install`) and per user (`pip install --user`):

```text
alice@srv01:~$ python3 -m pip install requests
error: externally-managed-environment

× This environment is externally managed
╰─> To install Python packages system-wide, try apt install
    python3-xyz, where xyz is the package you are trying to
...
```

Fedora and RHEL take a different approach: their pip sends `sudo pip install` to `/usr/local/lib`, away from RPM-owned files, instead of refusing. On every distribution, the right answer is the same: a **virtual environment** (venv), a private directory with its own `python`, `pip` and `site-packages`, built from the system interpreter.

```text
alice@srv01:~/project$ python3 -m venv .venv
alice@srv01:~/project$ source .venv/bin/activate
(.venv) alice@srv01:~/project$ which python pip
/home/alice/project/.venv/bin/python
/home/alice/project/.venv/bin/pip
(.venv) alice@srv01:~/project$ pip install requests
...
Successfully installed certifi-2026.11.20 charset_normalizer-3.5.2 idna-3.20 requests-2.34.2 urllib3-2.8.0
(.venv) alice@srv01:~/project$ pip freeze > requirements.txt
(.venv) alice@srv01:~/project$ deactivate
```

- On Debian and Ubuntu, `python3 -m venv` needs the **`python3-venv`** package (it provides `ensurepip`); without it the command stops and tells you which package to install.
- Activation only changes `PATH` and the prompt. Cron jobs and systemd units can skip it and call `/home/alice/project/.venv/bin/python script.py` directly.
- **`requirements.txt`** lists exact versions; recreate the environment elsewhere with `pip install -r requirements.txt`. Commit `requirements.txt` to Git, and put `.venv/` in `.gitignore` (lesson 4.4).
- For command-line applications from PyPI (ansible-core, yamllint), **pipx** creates one venv per application: `pipx install yamllint`.

## PEP 8 best practices

**PEP 8** is Python's official style guide. Consistent style makes scripts easier to review, and linters enforce it automatically in CI (shift-left, lesson 4.1).

| Rule | Example |
|---|---|
| 4 spaces per indentation level, no tabs | |
| Lines at most 79 characters (many teams allow more) | |
| Imports at the top, one per line, standard library first | `import os` then `import sys`, not `import os, sys` |
| Two blank lines around top-level functions and classes | |
| `snake_case` for functions and variables, `CapWords` for classes, `UPPER_CASE` for constants | `check_disk()`, `class DiskReport`, `THRESHOLD_PERCENT` |
| Spaces around operators and after commas | `if path is None:` |
| Compare with `None` using `is` / `is not`, not `==` | |

`pycodestyle` 2.15 on a short non-compliant file:

```text
alice@srv01:~$ cat style.py
import os,sys
def CheckDisk(Path):
  if Path==None: return False
  return os.path.isdir(Path)
alice@srv01:~$ pycodestyle style.py
style.py:1:10: E231 missing whitespace after ','
style.py:1:10: E401 multiple imports on one line
style.py:2:1: E302 expected 2 blank lines, found 0
style.py:3:3: E111 indentation is not a multiple of 4
style.py:3:10: E225 missing whitespace around operator
style.py:3:10: E711 comparison to None should be 'if cond is None:'
style.py:3:16: E701 multiple statements on one line (colon)
style.py:4:3: E111 indentation is not a multiple of 4
```

pycodestyle checks layout only (it does not flag the `CheckDisk` name); `flake8` and `ruff` add naming and logic checks, and `black` or `ruff format` rewrite the file automatically.

## Lab it yourself

1. Run `python3 --version` and `ls /usr/lib/python3*/EXTERNALLY-MANAGED` on a Debian or Ubuntu VM and a RHEL-family VM; on Debian/Ubuntu, try `python3 -m pip install requests` and read the error.
2. Create a venv in `~/project`, activate it, install `requests` and `pycodestyle`, and write `requirements.txt`. Delete the venv, recreate it, and reinstall with `pip install -r requirements.txt`.
3. Save `types_demo.py` and `disk_report.py`, run them, then lower `THRESHOLD_PERCENT` until the exit status becomes 1.
4. Introduce a tab and a two-space indent into `disk_report.py` and run it and `pycodestyle` on it.

## Key takeaways

- Python 3 only; Python 2 has been end of life since 2020. Use `python3`; versions differ by distribution.
- Blocks are defined by indentation (4 spaces); inconsistent indentation is an `IndentationError`.
- Core types: `bool`, `int`, `float`, `str`, `list`, `dict`; types are strong, so convert explicitly.
- The standard library (`os`, `sys`, `subprocess`, `pathlib`, `shutil`, `json`, `re`, `argparse`, `logging`) needs no installation; extras come from PyPI or `python3-*` packages.
- `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install`, `pip freeze > requirements.txt`, `pip install -r requirements.txt`, `deactivate`.
- PEP 668 makes pip refuse system-wide and `--user` installs into the distribution's Python on Debian/Ubuntu ("externally-managed-environment"); use a venv, pipx or distribution packages.
- PEP 8: 4-space indents, `snake_case`, `CapWords` classes, `UPPER_CASE` constants, one import per line, `is None`; check with pycodestyle, flake8 or ruff.
