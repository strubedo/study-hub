## What the exam asks

Topic 6.1 says **interpret**: you are shown a short Python 3 script and asked what it prints, what a variable holds at some point, or why it fails. You do not have to write Python from scratch. The skill is reading code line by line the way the interpreter does, keeping track of each variable's value and type. This lesson covers the building blocks; the next lesson applies them to the network scripts the exam likes (`requests`, `ncclient`, Netmiko).

Every script here was run with Python 3 and the output shown is the real output.

## Types you must recognise

| Type | Literal | Mutable? | Notes |
|---|---|---|---|
| `str` | `"R1"` or `'R1'` | No | Text. Single or double quotes are equivalent in Python (not in JSON) |
| `int` | `1500` | No | Whole numbers, no size limit |
| `float` | `7.5` | No | Decimals; `10 / 4` is `2.5`, `10 // 4` is `2` |
| `bool` | `True`, `False` | No | Capitalised. A subclass of `int` |
| `NoneType` | `None` | No | "No value". Functions without `return` return `None` |
| `list` | `[10, 20, 30]` | Yes | Ordered, indexed, duplicates allowed |
| `tuple` | `("192.0.2.10", 22)` | No | Ordered, indexed, fixed once created |
| `dict` | `{"name": "Gi1", "mtu": 1500}` | Yes | Key to value; keys unique; keeps insertion order (Python 3.7+) |
| `set` | `{10, 20, 30}` | Yes | Unordered, **no duplicates**, no indexing; `{}` is an empty dict, not a set |

```python
hostname = "R1-EDGE"
vlans = [10, 20, 30, 99]
mgmt = ("192.0.2.10", 22)
intf = {"name": "GigabitEthernet0/0/1", "enabled": True, "mtu": 1500}
allowed = {10, 20, 20, 30}
backup = None

print(type(hostname).__name__, type(vlans).__name__, type(mgmt).__name__)
print(type(intf).__name__, type(allowed).__name__, type(backup).__name__)
print(len(hostname), len(vlans), len(allowed))
```

```text
str list tuple
dict set NoneType
7 4 3
```

`len(allowed)` is 3, not 4: the duplicate 20 disappears when the set is built.

## Indexing and slicing

Indexes start at **0**; negative indexes count from the end (`-1` is the last item). A slice `[start:stop]` includes `start` and **excludes** `stop`; either can be left out; a third number is the step. Strings, lists and tuples all index the same way. Dictionaries are looked up by **key**, not position.

```python
print(hostname[0], hostname[-4:], hostname[:2])
print(vlans[1], vlans[-1], vlans[1:3], vlans[::2])
print(intf["name"].split("/")[-1], intf.get("speed", "auto"))
print(intf["enabled"] and intf["mtu"] > 1400)
```

```text
R EDGE R1
20 99 [20, 30] [10, 30]
1 auto
True
```

- `vlans[1:3]` is items 1 and 2: `[20, 30]`.
- `"GigabitEthernet0/0/1".split("/")` gives `['GigabitEthernet0', '0', '1']`; `[-1]` takes the last part.
- `intf["speed"]` would raise `KeyError`; `intf.get("speed", "auto")` returns the default instead.

> **Exam tip:** Most "what is printed" questions hinge on an off-by-one: index 0 is the first item, and the stop value of a slice is not included. Write the indexes above the items on your scratch board before you answer.

## Conditionals and loops

Python marks blocks by **indentation** after a line ending in a colon. `if` / `elif` / `else` run the first branch whose condition is true. `for` walks over any sequence (a list, the characters of a string, a dictionary's keys, or `dict.items()` for key and value pairs). `while` repeats while its condition stays true. `break` leaves the loop; `continue` skips to the next pass.

```python
interfaces = [
    {"name": "Gi0/0/0", "status": "up", "errors": 0},
    {"name": "Gi0/0/1", "status": "down", "errors": 12},
    {"name": "Gi0/0/2", "status": "up", "errors": 250},
]

problems = 0
for intf in interfaces:
    if intf["status"] != "up":
        print(f"{intf['name']}: DOWN")
        problems += 1
    elif intf["errors"] > 100:
        print(f"{intf['name']}: up with {intf['errors']} errors")
        problems += 1
    else:
        print(f"{intf['name']}: OK")
print(f"{problems} of {len(interfaces)} interfaces need attention")

for vlan_id in range(10, 40, 10):
    print("vlan", vlan_id)

count = 0
while count < 3:
    count += 1
print("count is", count)
```

```text
Gi0/0/0: OK
Gi0/0/1: DOWN
Gi0/0/2: up with 250 errors
2 of 3 interfaces need attention
vlan 10
vlan 20
vlan 30
count is 3
```

Gi0/0/1 has 12 errors but is reported only as DOWN: once the `if` branch runs, the `elif` is never tested. `range(10, 40, 10)` stops **before** 40.

A **list comprehension** is a loop written inside brackets: `[d for d in devices if "SW" in d]` builds a new list of the items that match. Read it as "for each d in devices, keep d if the condition is true".

## Functions, return values and f-strings

`def` defines a function; parameters can have **default values**; `return` hands a value back (no `return` means the function returns `None`). Arguments can be passed by position or by name.

```python
def to_wildcard(mask):
    """Return the wildcard mask for a dotted-decimal subnet mask."""
    octets = mask.split(".")
    return ".".join(str(255 - int(octet)) for octet in octets)


def describe(name, vlan=1, shutdown=False):
    state = "shutdown" if shutdown else "no shutdown"
    return f"interface {name} / vlan {vlan} / {state}"


print(to_wildcard("255.255.255.0"))
print(to_wildcard("255.255.240.0"))
print(describe("Gi1/0/5"))
print(describe("Gi1/0/6", vlan=20, shutdown=True))
speed = 1000
print(f"Speed: {speed} Mb/s, {speed / 1000:.1f} Gb/s, padded [{speed:>6}]")
```

```text
0.0.0.255
0.0.15.255
interface Gi1/0/5 / vlan 1 / no shutdown
interface Gi1/0/6 / vlan 20 / shutdown
Speed: 1000 Mb/s, 1.0 Gb/s, padded [  1000]
```

An **f-string** (`f"..."`) evaluates each `{expression}` and inserts it. After a colon comes a format: `:.1f` is one decimal place, `:>6` right-aligns in six characters, `:<10` left-aligns in ten. Inside an f-string delimited by double quotes, use single quotes for dictionary keys, as in `f"{intf['name']}"`.

## import

`import json` makes the standard library's `json` module available as `json.loads(...)`; `from requests.auth import HTTPBasicAuth` imports one name so it can be used without the module prefix. Standard-library modules (`json`, `os`, `ipaddress`, `time`) are always present; third-party ones (`requests`, `ncclient`, `netmiko`) must be installed with `pip`, or the script stops at the import line with `ModuleNotFoundError`.

## Exceptions: try, except, finally

An error at run time raises an **exception**. If nothing catches it, the script stops with a traceback. `try` runs code that might fail; the matching `except` block handles a named exception type; `else` runs only if no exception happened; `finally` runs **every time**, even after `break`, `continue` or `return`.

```python
raw_values = ["1500", "9000", "jumbo", "1400"]
valid = []
for value in raw_values:
    try:
        mtu = int(value)
    except ValueError:
        print(f"skipping {value!r}: not a number")
        continue
    valid.append(mtu)
print(valid, max(valid))

device = {"hostname": "R1", "mgmt_ip": "192.0.2.10"}
try:
    print(device["serial"])
except KeyError as err:
    print("missing key:", err)
finally:
    print("lookup finished")
```

```text
skipping 'jumbo': not a number
[1500, 9000, 1400] 9000
missing key: 'serial'
lookup finished
```

Common exceptions to recognise: `KeyError` (missing dictionary key), `IndexError` (list index out of range), `ValueError` (right type, bad value, such as `int("jumbo")`), `TypeError` (wrong type, such as `"MTU " + 1500`), `ModuleNotFoundError`, `FileNotFoundError`, and `json.JSONDecodeError` (invalid JSON).

## Files with `with open`, and JSON

`with open(path, mode) as f:` opens a file and **closes it automatically** when the block ends, even after an exception. Modes: `"r"` read (default), `"w"` write (truncates), `"a"` append.

The `json` module converts between JSON text and Python objects:

| Function | Direction |
|---|---|
| `json.loads(text)` | JSON **string** to Python object |
| `json.load(f)` | JSON from an open **file** to Python object |
| `json.dumps(obj)` | Python object to JSON **string** |
| `json.dump(obj, f)` | Python object to an open **file** |

```python
import json

with open("r1.json", "w") as f:
    json.dump(device, f)

with open("r1.json") as f:
    loaded = json.load(f)
print(loaded == device, type(loaded).__name__)

text = '{"name": "Loopback0", "enabled": true, "vlan": null, "mtu": 1514}'
data = json.loads(text)
print(data["enabled"], data["vlan"], type(data["mtu"]).__name__)
print(json.dumps(data))
print(json.dumps({"vlans": (10, 20)}, indent=2))
```

```text
True dict
True None int
{"name": "Loopback0", "enabled": true, "vlan": null, "mtu": 1514}
{
  "vlans": [
    10,
    20
  ]
}
```

JSON `true` / `false` / `null` become Python `True` / `False` / `None` and back again; a JSON object becomes a `dict`, an array becomes a `list`, and a Python tuple is written out as a JSON array. Topic 6.2 covers JSON syntax itself.

> **Watch out:** `json.loads` takes a **string**, `json.load` takes a **file object**. `requests` gives you a third way: `response.json()` parses the HTTP body for you.

## Key takeaways

- Know the types: `str`, `int`, `float`, `bool` (`True`/`False`), `None`, `list` (mutable), `tuple` (immutable), `dict` (key to value), `set` (no duplicates, unordered).
- Indexes start at 0, `-1` is the last item, and a slice `[a:b]` stops before `b`.
- `if` / `elif` / `else` runs only the first true branch; `break` leaves a loop, `continue` skips to the next pass; blocks are defined by indentation.
- Functions return a value with `return` (or `None`); default parameters fill in missing arguments; f-strings insert `{expressions}` with optional formats such as `:>6` or `:.1f`.
- `try` / `except` catches named exceptions (`KeyError`, `IndexError`, `ValueError`, `TypeError`, `json.JSONDecodeError`); `finally` always runs.
- `with open(...)` closes the file for you; `json.loads` / `json.dumps` work on strings, `json.load` / `json.dump` on files.
