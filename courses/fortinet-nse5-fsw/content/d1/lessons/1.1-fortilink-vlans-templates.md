## The VLANs FortiLink creates for you

When a FortiGate starts managing FortiSwitch units, the switch controller creates a small set of FortiLink VLAN interfaces automatically. Each serves one *type* of traffic, and each is defined by a **VLAN interface template**:

| Traffic type (`initial-config vlans` keyword) | Purpose | Default template IP |
|---|---|---|
| `default-vlan` | Default (native) VLAN assigned to all switch ports when a switch is discovered | Not applicable |
| `quarantine` | Quarantined hosts | `10.255.11.1/24` |
| `rspan` | RSPAN/ERSPAN mirrored traffic | `10.255.12.1/24` |
| `voice` | Voice devices | Not applicable |
| `video` | Video devices | Not applicable |
| `nac` | NAC onboarding devices | Not applicable |
| `nac-segment` | Primary interface of the NAC segment | `10.255.13.1/24` |

The three addresses come out of the **switch-controller reserved network**, which defaults to `10.255.0.0/16`:

```text
FGT-HQ # config system global
FGT-HQ (global) # set switch-controller-reserved-network 10.255.0.0 255.255.0.0
FGT-HQ (global) # end
```

> **Exam tip:** remember the pattern — quarantine `.11`, RSPAN `.12`, NAC segment `.13`, all `/24` inside `10.255.0.0/16`. If 10.255.0.0/16 overlaps something real in your network, change the reserved network **before** switches are authorized.

## VLAN interface templates

Templates let you decide, per VDOM, what those auto-created VLAN interfaces look like. There are two objects:

1. `config switch-controller initial-config template` — one entry per template: VLAN ID, IP, admin access, auto-IP and DHCP server.
2. `config switch-controller initial-config vlans` — maps each traffic type to a template.

```text
FGT-HQ # config switch-controller initial-config template
FGT-HQ (template) # edit "quarantine"
FGT-HQ (quarantine) # set vlanid 4093
FGT-HQ (quarantine) # set dhcp-server enable
FGT-HQ (quarantine) # next
FGT-HQ (template) # edit "voice"
FGT-HQ (voice) # set vlanid 20
FGT-HQ (voice) # set auto-ip disable
FGT-HQ (voice) # set ip 10.10.20.1 255.255.255.0
FGT-HQ (voice) # set allowaccess ping
FGT-HQ (voice) # set dhcp-server enable
FGT-HQ (voice) # end
FGT-HQ # config switch-controller initial-config vlans
FGT-HQ (vlans) # set quarantine "quarantine"
FGT-HQ (vlans) # set voice "voice"
FGT-HQ (vlans) # end
```

| Template setting | Meaning |
|---|---|
| `vlanid` | VLAN ID for that traffic type (1–4094; default 4094) |
| `auto-ip` | **Enabled by default.** The switch controller picks an unused /24 from the reserved network |
| `ip` | Only configurable when `auto-ip` is disabled |
| `allowaccess` | Management protocols allowed on the VLAN interface |
| `dhcp-server` | When enabled, the switch controller also creates a DHCP server for that VLAN interface |

> **Watch out:** you can only create VLAN interface templates **while the FortiGate has not authorized any FortiSwitch unit yet**. Fortinet's advice is to finish templates (and other "before authorization" settings) first and only then physically connect the switches.

### Interface names in VDOMs

To keep names unique system-wide:

- **root VDOM:** the VLAN interface takes the template name (`quarantine`).
- **Other VDOMs:** the name is the template name plus the interface's SNMP index, e.g. template `quarantine` with SNMP index 29 becomes `quarantine.29`.

That is why exhibits from multi-VDOM boxes show ports with `set vlan "_default.39"` and `set allowed-vlans "quarantine.39"`.

## The FortiLink management VLAN

The FortiGate manages switches over a dedicated management VLAN on the FortiLink interface. It is **4094 by default** (range 1–4094) and is set per FortiLink interface:

```text
FGT-HQ # config system interface
FGT-HQ (interface) # edit "fortilink"
FGT-HQ (fortilink) # set fortilink enable
FGT-HQ (fortilink) # set switch-controller-mgmt-vlan 4094
FGT-HQ (fortilink) # end
```

Pick a different value only if 4094 is already in use downstream (for example, a third-party switch in the FortiLink path that uses 4094 for something else). Do not confuse this VLAN with the FortiLink interface's own IP subnet (for example `10.255.1.1/24`), which is the address the switches receive by DHCP from the FortiGate.

## What the quarantine and RSPAN VLANs are used by

You will meet these VLANs again in other domains, but know what they are for now:

- **quarantine** — hosts quarantined by the FortiGate are moved here; the interface is set up with a captive portal and DHCP server so the user sees why.
- **rspan** — the destination VLAN for remote port mirroring (RSPAN/ERSPAN) of switch traffic.
- **voice / video** — typical targets of LLDP-MED network policies and dynamic port policies (lesson 1.2).
- **nac / onboarding** — where unknown devices land before a NAC policy moves them to their real VLAN.
- **nac-segment** — the primary interface for NAC segments.

## Comparing with Cisco

On a Cisco campus there is nothing like a "template": the voice VLAN, quarantine VLAN and SPAN destination VLAN are just VLANs you create and SVIs you route. FortiLink automates the creation of both the Layer 2 VLAN on every switch **and** the Layer 3 interface plus DHCP server on the FortiGate in one step. The reserved-network concept is closest to reserving an internal address block for infrastructure, which is why it must not overlap production subnets.

## Lab it yourself

These objects exist entirely on the FortiGate, so the FortiGate-VM permanent trial is enough, provided no switch is authorized (a trial VM never has one):

1. `config switch-controller initial-config template` — create `quarantine`, `rspan`, `voice` and `video` templates with different VLAN IDs; leave `auto-ip` enabled on one and set a static `ip` on another.
2. `config switch-controller initial-config vlans` — map the traffic types to your templates.
3. `show system interface` — check whether VLAN interfaces were created on your build and what they are named. Note how many interfaces the trial lets you create before hitting its interface cap.
4. `config system global` → `set switch-controller-reserved-network` — change it and observe whether existing auto-IP templates change.

## Key takeaways

- FortiLink auto-creates VLAN interfaces for default, quarantine, RSPAN, voice, video, NAC onboarding and NAC segment traffic.
- `initial-config template` defines each VLAN interface; `initial-config vlans` maps traffic types to templates.
- Templates can only be created before any FortiSwitch is authorized.
- `switch-controller-reserved-network` defaults to `10.255.0.0/16`; default template IPs are quarantine `10.255.11.1/24`, RSPAN `10.255.12.1/24`, NAC segment `10.255.13.1/24`.
- `auto-ip` is enabled by default; a static `ip` can only be set when `auto-ip` is disabled.
- In non-root VDOMs, auto-created names get a `.<SNMP index>` suffix.
- The FortiLink management VLAN is 4094 by default (`switch-controller-mgmt-vlan`).
