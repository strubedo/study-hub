## Pay-as-you-go licensing through Azure Arc

Windows Server 2025 can be licensed as a **subscription** instead of a perpetual license. You connect the server to **Azure Arc**, turn on **pay-as-you-go**, and Azure activates the server and bills it through your Azure subscription. You never type a product key.

Facts Microsoft documents for this model:

- **Prerequisites:** Windows Server 2025 **Standard or Datacenter**; Arc-enabled with the Azure Connected Machine agent **version 1.47 or later**; **not already activated** with another license type (OEM, retail or volume license); and an active internet connection.
- **Billing:** per core, per hour, the same rate for Standard and Datacenter. There is no minimum core count per machine and no fixed increment; if the core count changes, billing adjusts within 24 hours.
- **Trial:** the first **seven days** after enabling are free.
- **CALs:** no CALs for standard functionality; **RDS CALs are still required**.
- **Scope:** the license covers *that device only*. It gives no extra rights for VMs on the same server, so **AVMA is not available** and every VM needs its own license. Host and VMs may run different OS versions and mix license types.
- **Stopping the meter:** shutting down or deprovisioning does *not* stop billing. Disable pay-as-you-go in the Azure portal, PowerShell or API, or remove the machine from Arc.
- **Where to enable:** during setup on the **Choose a licensing method** screen (retail media only; evaluation and volume media skip the product key page), or afterward in the Azure portal under **Machines - Azure Arc**.
- **Not for Azure VMs:** pay-as-you-go through Arc is for machines outside Azure.

Enrolled machines also receive Azure Update Manager, Change Tracking and Inventory, and Azure Machine Configuration at no extra cost, plus access to Windows Admin Center in Azure, Best Practices Assessment, Remote Support and others (with possible compute, storage or log-ingestion charges).

> **Exam tip:** Pay-as-you-go is a *licensing* model. It removes the product key and the base CAL requirement. It does not remove RDS CALs and does not extend VM rights.

> **Real world:** Windows Server Management enabled by Azure Arc is a different offer. It is for servers that already have Software Assurance or subscription licenses, and it unlocks the same Azure management benefits.

## Hardware requirements

These minimums apply to both Server Core and Desktop Experience, in Standard and Datacenter.

| Component | Minimum for Windows Server 2025 |
|---|---|
| Processor | 1.4 GHz 64-bit, x64 instruction set, NX and DEP, CMPXCHG16b, LAHF/SAHF, PrefetchW, second-level address translation (EPT or NPT), plus **SSE4.2** and **POPCNT** (new requirements for 2025) |
| RAM | **2 GB** for Server Core; **2 GB** for Desktop Experience (4 GB recommended); ECC or similar for physical hosts |
| Disk | **32 GB** absolute minimum (Server Core with the IIS role); Desktop Experience needs about 4 GB more; more for network installs and for machines with over 16 GB RAM (paging, dump files) |
| Network | Ethernet adapter of at least **1 Gbps**, PCI Express compliant |
| Storage controller | PCI Express compliant; PATA, ATA, IDE and EIDE are not allowed for boot, page or data drives |
| Optional | UEFI 2.3.1c with Secure Boot, TPM (version 2.0 for BitLocker-class features), SVGA display |

You can check CPU capabilities with **Coreinfo** from Sysinternals.

**Virtual machine trap:** a VM with 1 core and the minimum 1,024 MB RAM fails to install. Give it **1,280 MB or more** during setup (you can reduce it to 1,024 MB afterward depending on workload), or use `SHIFT+F10` in setup to create the partition and a page file by hand. Real labs should simply use 4 GB.

**Secured-core server** needs more: Intel VT-d or AMD-Vi (IOMMU), Kernel DMA Protection, DRTM, TPM 2.0, Secure Boot and virtualization-based security.

> **Watch out:** The old 1 GB Server Core and 512 MB minimums belong to Windows Server 2022 and earlier. Questions about 2025 use 2 GB and the 1,280 MB VM workaround.

## What is new in Windows Server 2025

Only items Microsoft documents are listed here; later domains cover each in depth.

| Area | Change |
|---|---|
| Licensing and management | Azure Arc pay-as-you-go; Windows Server Management enabled by Azure Arc; Hotpatch for Arc-connected servers |
| Security | Credential Guard enabled by default on devices that meet requirements; Windows LAPS; delegated managed service accounts (dMSA); TLS 1.0 and 1.1 disabled by default; NTLMv1 removed |
| SMB | SMB over QUIC in Standard and Datacenter; SMB NTLM blocking for outbound connections; SMB authentication rate limiter |
| Active Directory | Optional 32k database page size; new forest/domain functional level |
| Remote access | OpenSSH server installed by default (not enabled) |
| Virtualization | GPU partitioning with live migration and HA; Accelerated Networking (preview) |
| Platform | NVMe performance, Storage Replica compression, Bluetooth and Wi-Fi support, Windows Terminal, DTrace, Windows 11 style shell |
| Upgrades | In-place upgrade directly from Windows Server 2012 R2 and later (up to four versions at once) |

> **Watch out:** Deprecated does not mean removed. WSUS, NLB and NTLMv2 are deprecated but still shipped and supported; NTLMv1 is gone.

## Lab it yourself

1. In Hyper-V create a Generation 2 VM with 4 GB RAM. Then, as an experiment, create a second VM with 1 core and 1,024 MB static memory and watch setup fail; raise it to 1,280 MB and retry.
2. On your lab PC run Sysinternals `coreinfo -f` and confirm SSE4.2 and POPCNT show as supported (`*`).
3. In the 2025 VM run `Get-ComputerInfo | Select-Object OsName, OsVersion, WindowsEditionId`.
4. Browse the Azure portal's **Machines - Azure Arc** blade (read only) and find where the **Windows Server** license option lives.

## Key takeaways

- Pay-as-you-go needs 2025 Standard or Datacenter, Arc agent 1.47+, and a machine not already activated with another license type.
- It bills per core per hour at one rate for both editions, gives a seven-day trial, and keeps billing until you disable it.
- No base CALs under pay-as-you-go, but RDS CALs remain; no extra VM rights and no AVMA.
- 2025 minimums: 1.4 GHz x64 with SSE4.2 and POPCNT, 2 GB RAM, 32 GB disk, 1 Gbps NIC.
- A minimum-spec VM needs 1,280 MB RAM to install.
- In-place upgrade to 2025 is allowed from 2012 R2 onward; NTLMv1 is removed, WSUS is deprecated but supported.
